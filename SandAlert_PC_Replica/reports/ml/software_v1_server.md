# Software-v1 服务器 CPU 评估

日期：2026-07-24
结论范围：仅限合成留出场景（`synthetic_holdout_only`）

## 运行边界

- 数据集：900 个单通道窗口，2 MHz，8192 点，随机种子 `20260724`。
- 分组切分：训练 680、验证 65、测试 155；同一模拟场景组不跨集合。
- 服务器环境：Python 3.10.20、PyTorch 2.13.0+cpu，`cuda_available=false`。
- 训练约束：CPU、32 计算线程、8 个数据加载进程、`nice=10`。
- 未安装或修改 NVIDIA 驱动，未加载内核模块，未重启服务器。

## 测试集结果

| 方法 | 撞击 F1 | 撞击 AP | IPS MAE | 相对能量 MAE |
|---|---:|---:|---:|---:|
| 现有 DSP | 0.7500 | 0.6060 | 24009.26 | 43.27 dB |
| 特征 + 梯度提升 | 0.9851 | 0.9998 | 195.31 | 1.99 dB |
| 小型多任务 TCN | 0.9254 | 0.9836 | 138.51 | 26.29 dB |

按预设研究门槛，TCN 在合成留出集上的撞击 F1 和 IPS MAE 均不劣于 DSP，且至少一项改善超过 10%，因此可进入软件影子模式。这个判定不等价于获得现场部署资格。

## 解释与下一步

这组结果只能证明模拟、训练、导出和 CPU 影子推理链路已打通，不能证明真实 g/s 或现场 IPS 精度。TCN 的相对能量头明显弱于特征模型，是当前最突出的模型问题；后续应优先检查损失权重、标签尺度和多任务负迁移。

在气固试验台可用前，候选模型保持只读影子输出，不参与 g/s、累计砂量、报警或继电器。试验台建成后需要使用 AE 原始波形，并以称量投砂、粒径、气速、持续时间和回收质量形成真实标定集。
